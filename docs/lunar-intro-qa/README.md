# 历史筛选、农历节气与轮换开场验收

2026-11-05，本地生产构建；使用独立合成记录与只读普通成员夹具，没有修改真实账户或复盘。

## 行为

- 历史的类型、年份、月份恢复紧凑 shadcn NativeSelect。未选年份时月份禁用；选2026年、11月、每日复盘得到4篇合成记录，切页后保留原值；键盘从年份Tab到月份。其他填写类选项保持RadioGroup。
- 阶段月历明确七列六周，外月格留空。公历下方显示农历，初一显示月名，节气优先显示。2026年11月7日立冬、22日小雪；切到12月后为7日大雪、22日冬至。原记录/今天/禁用规则保留，月份浏览不选日，键盘切月后焦点仍在月份按钮；打开11月3日已验证记录，退出回到日历。
- 六类各12句，共72句，包含原创句和公版诗文。每类洗牌池用完才循环，边界不连续重复；六类各连续进入两次均换句。一次访问从首题回引导保持同一句。标点分行、全文可访问和打字机仍有效。
- 在1440px桌面及320/390/820px检查历史、月历和六类开场；无横向溢出。320px检查月度长句和决策四行诗句，开始按钮保持可见；桌面四行文案按钮底边为723px，900px高视口容纳完整开场。
- 只读普通成员夹具使用旧白色配色和reduceMotion：固定类别色仍可读，开场直接显示全文，没有隐藏字。两个验收页控制台均无error/warn。

当前截图是浏览器实际输出；图片尺寸可能小于设定CSS视口。DOM几何、筛选值、抽样文案与控制台记录见[geometry.json](geometry.json)。抽样跨过已有文案池的循环边界，因此任意连续12次样本不保证全部唯一；完整池耗尽和边界防重复由独立测试验证。
