## 复查

`check.cjs` 通过真实导航和只读 API 拦截运行，遇到非 GET 请求立即失败。需要一个已经登录、使用独立合成数据的同源测试地址，以及本机 Chrome 和 Playwright：

```powershell
$env:PLAYWRIGHT_MODULE='你的 Playwright 模块绝对路径'
node docs/workspace-readme-qa/check.cjs http://127.0.0.1:3192
```

本次夹具使用3192前端代理与3193隔离后端；仅此夹具在本机自动认证。不要把生产地址替换进去。`baseline.json` 与 `final-checks.json` 保存实测尺寸和检查结果。长账户组件的截图临时隐藏固定顶部导航，避免截图工具滚动定位时把导航画在组件中部；页面尺寸与元素边界检查不隐藏导航。
