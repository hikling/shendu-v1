## 本次变化

- 历史卡片取消分散居中的上下结构。类别与状态置顶，日期、标题、摘要左对齐，类别插画靠右下，底部意图与打开入口对齐。桌面两列、820px 及以下单列；普通桌面短卡实测约 279px，页头约 211px。
- 数据备份与账户管理使用插画页头、宋体大标题和纸面分组；备份采用紫色，成员管理采用绿色。个人备份、整站迁移、外部目标与运行记录分别成组。
- 账户与安全、设置及其主题／阶段／指南子框使用同一家族的插画、标题、输入边界与操作区。账户安全采用橄榄绿，设置采用琥珀色，阶段设置采用蓝色。
- 复用七张已审核的相关本地插画，无新依赖或图像服务。危险操作保留清楚的提示，表单、权限、加密及请求协议不变。
- 修复异步备份错误页的重试按钮未绑定；补齐 701–820px 用户表格转卡片时的结构规则。

## 已通过检查

- `npm test`：生产构建与 **112/112** 项测试通过；最终重跑包含重试与表格修正。`npm run check`、`git diff --check` 通过。
- `npm run smoke:ui -- http://127.0.0.1:3192`：健康、HTML、应用模块、真实组件 JS/CSS 及本次两个独立样式资源通过。
- 独立源码审查：原备份字段、密码约束、导出／恢复路径、成员权限／删除保护、主题／阶段设置、转义和组件岛生命周期保持合同。发现的两个问题均已修复并实际验收。
- 浏览器覆盖 1280、820、390、320px。历史卡片及工具界面没有内容横向溢出；320px 账户弹窗实测宽 300px，长内容在弹窗内部滚动。820px 用户表格整组切换为带字段名的卡片。
- 历史按 2025 年／12 月／“冬日的一次散步”组合筛选只显示一条；输入后光标保留。打开记录并退出，返回历史页且保留原筛选。无匹配与空库状态均正常。
- 成员搜索用实际键盘输入并离开字段后正确筛选。设置 → 主题／阶段／指南 → 返回设置可重复往返，焦点与背景隔离正常。
- 普通成员没有账户管理入口及整站备份分区；全白自定义主题仍保留可读的深墨文字和明确按钮。减少动态设置下历史卡片计算过渡时间为 `0s`。
- 503 只读代理先令备份加载失败，点击“重试”后恢复正常分区；不依赖旧的导航绑定。
- 正常验收及最终主题页的浏览器 error/warn 日志为空。测试标签已关闭，视口覆盖已恢复。

## 验收边界

浏览器使用隔离数据库与只读响应代理覆盖空记录、普通成员、白色主题、减少动态和首轮 503。没有保存用户主题、修改密码、创建／删除真实成员、导出／恢复真实备份或连接外部备份服务。实际备份往返、权限隔离、会话、加密和日期规则由完整测试覆盖；界面验收不代替这些测试。

概览、六类沉浸复盘、行动验证与阶段日历不在本次样式改动范围。
