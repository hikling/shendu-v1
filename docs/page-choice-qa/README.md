## 实际浏览器

在本地隔离的合成数据环境验收，未修改真实账户、密码或记录。填写的合成草稿和阶段修改均放弃；偏好失败检查通过只读代理拒绝写入。

- 每日状态：五项直接显示，鼠标选择写回原生状态字段；箭头移焦、空格确认后可见选中状态与原字段一致。320px自然分两行，没有弹出选择层。
- 历史筛选：类型、年份、月份直接显示；选2026年和11月，原生字段与8条结果一致；无年份时月份禁用。
- 日历：鼠标上/下个月与键盘Enter浏览正常且焦点留在按钮；浏览不选择日期。发现月份标题遮挡鼠标，已把导航层置于标题之上并重新实际验证。
- 打开11月3日已验证记录后退出，返回日历并聚焦原日期，未回到概览。
- 阶段设置：清空必填方向后保存会聚焦原输入；离开弹出未保存提示，继续填写保留内容，放弃后返回日历。
- 设置/阶段/指南为独立页，页面没有Dialog及背景遮罩；指南返回、阶段返回可用。
- 普通成员、旧全白颜色数据和减少动态模式下界面可读。只读代理造成保存失败时，保留新选项、原已保存动态状态，解除忙碌且继续保护离开。
- 空日历显示零统计、清晰的无待验证状态。最终主预览及空数据页面没有控制台错误或警告；只读失败用例展示预期“请求失败”。

320px日历和卡片边界为16–304px，文档宽320px；390px边界16–367px，文档宽383px；820px边界20–793px，文档宽813px（浏览器滚动条占7px）。均不超过视口。390/820px的测量保存在[geometry.json](geometry.json)。
