# 财务收支与压缩凭证

在顶部「财务收支」或 `/finance` 查看账本；新建每日复盘在睡眠、精力后显示「今天，花销多少？」。旧记录沿用原模板，不补造过去的花销。

## 逐行记下花销

每日花销题和财务页都使用大文本框，每行写金额或加减算式，空格后写用途，例如：

```text
60 打车
50 吃饭
```

下方实时显示两笔、合计 `110.00` 元，并自动归为交通、餐饮；吃饭、聚餐、团建等餐饮用途会合并识别，无法识别的用途直接作为分类（如 `60 修鞋` 归为“修鞋”），仍可在每行修正分类。也可写 `8+8+8-1 早餐`，这一行合计 `23.00` 元。支持两位小数，一次最多30笔、6000个字符；空行会跳过，格式不完整的行会标出行号，修正后才能确认。输入和计算本身不会创建账目。

点击「确认入账」后逐笔保存。如果中途失败，已成功的行会从输入框移除，留下未完成的行供重试；不要重新抄回已成功的行。每日复盘保存草稿时会保留未确认的文字；旧版单笔草稿的金额、用途、分类、备注及凭证关联继续保留。

「详细录入」可设置日期、收支类型、分类和备注，也提供逐项填写多笔收支的入口。减号只用于金额算式，退款请使用「退款」并选择原支出，内部转账与还款使用「不计收支」。金额为人民币，精确到分。「收支差额」不是银行卡余额。

「确认入账」后独立保存到账本，删除复盘草稿不删除已入账账目。未确认的花销需先确认或清空才能进入下一题、提交复盘。暂时不记可跳过；「今天没有花销」与未记录区分。账目可补记、更正、移入回收站或恢复，分类随用途自动生成和复用，不再提供分类管理入口。提交复盘后保留当时财务摘要，后续订正账本不改写锁定复盘。

## 按月查看收支

月份栏支持上个月、下个月和回到本月，也可打开月份面板选择年份与月份。打开面板、浏览年份不会重新读取账本，选定不同月份才更新数据。月份只决定查看范围；补记其他日期的账目请用「详细录入」。

左侧饼图显示所选整月的分类支出，右侧饼图显示某一天的分类支出，可用日历切换所选月内的日期。本月默认今天，其他月份默认最近有支出的日期或月末。饼图只按实际支出占比绘制；退款及净支出另行列出。分类金额和百分比同时提供文字列表；没有支出时显示空态。

收支明细按日期排列，搜索用途或备注、收支类型和分类筛选集中在明细上方。两张图和期间总计按完整期间计算，列表筛选及分页不改变它们。新记账的实际日期显示在输入区；补记其他日期请用详细录入。

## 截图记账

选择图片或在记账区域粘贴截图，先在当前设备压缩和识别。识别引擎及中文/英文语言包由本站提供，不调用云端识别。首次需要加载资源，手机速度取决于设备；处理过程中可取消。结果可能出错，必须核对日期、金额、类型和分类后入账。疑似重复项默认不勾选，可核对后保留；不同消费金额相同不会被自动删除。

每批最多20张，支持PNG、JPEG、WebP，限制文件大小和解码像素。长截图以文字可读为准，不承诺固定压缩率。**原图仅在设备内临时处理，不上传、不长期保存**；S3保留压缩清晰图和小缩略图，列表按需取缩略图，点击再取清晰图。未配置图片存储仍可本地识别和手填，但不会保存凭证，界面会提示。配置了存储但上传或校验失败时，本批次会停止，不能把识别到的金额直接当成已附截图的账目保存；修正配置或网页跨域权限后重新处理。未配置存储而只做文字识别时，核对弹窗会明确标注图片未保存，并要求确认本次只入账文字。

收支明细中，有截图的账目显示「查看截图 · N 张」，点击文字或缩略图可查看压缩清晰图；没有关联的账目标明「未附截图」。截图处理完成后仍须在核对弹窗确认入账，才能在收支明细中找到对应账目。尚未配置存储时只识别，不会保存可回看的图片。过去未关联图片的账目不能自动推断原图：在该笔账目的「修改」中点「补传截图」，上传成功后再点「保存修改」，即可关联原账目；金额、日期和用途不会被识别结果覆盖。

## 私有S3设置

打开「图片存储设置」，可复用本人已有S3备份目标，或填写独立的服务地址、地区、桶、目录、访问密钥和路径风格。InfiniCLOUD的WebDAV备份继续可用，本版网页凭证直传采用S3接口。

设置中可直接修改已保存配置，并用「测试连接」检测当前输入，测试不会保存修改。测试会写入、读回并清理一个小文件，只说明服务器读写权限；网页跨域上传和图片SHA-256校验仍由实际上传检验。测试失败会保留输入，密钥不回显。

「删除配置」需确认，只清除保存的连接配置与密钥，不删除账目或S3中的图片。已保存的凭证关联会保留，断开后暂不能看图；重新填写原存储位置及正确密钥可恢复查看。已有已保存凭证时不能直接改用其他存储桶或目录。未完成上传的索引会清理，便于修正错误配置。

桶保持私有。慎独按账户生成短时授权，浏览器直接与S3传输压缩图，慎独主机不保存图片。长期密钥只在服务端加密保存，不发送给网页。账目、图片仅本人可读；使用日志不显示金额、用途和截图内容。

存储需支持S3预签名PUT/GET，并配置CORS允许自己的网站，例如 `https://shendu.example.com`。普通S3沿用SHA-256上传和HEAD返回校验值；Cloudflare R2原生接口改为HEAD检查后临时读回压缩图，核对实际内容的SHA-256。读回只用于入账前校验，不落盘保存，不能只凭自定义元数据判定成功。无需把桶公开。请在应用中填写密钥，不要发到聊天或公开代码。

### Cloudflare R2

服务地址使用R2控制台提供的S3接口 `https://<ACCOUNT_ID>.r2.cloudflarestorage.com`，地区填 `auto`，可启用路径式地址。预签名链接不能改用公开访问域名。依据[Cloudflare S3兼容性说明](https://developers.cloudflare.com/r2/api/s3/api/)及[预签名链接说明](https://developers.cloudflare.com/r2/api/s3/presigned-urls/)，程序仅对原生R2接口选择内容读回校验，其余S3服务保持原校验方式。

在存储桶「设置 → CORS策略」添加下列规则，把示例域名替换为慎独实际访问地址（协议和域名必须一致，不含末尾斜杠）。服务器连接测试通过，不代表浏览器跨域上传已放行。[Cloudflare CORS说明](https://developers.cloudflare.com/r2/buckets/cors/)

```json
[
  {
    "AllowedOrigins": ["https://shendu.example.com"],
    "AllowedMethods": ["GET", "PUT", "HEAD"],
    "AllowedHeaders": ["Content-Type", "x-amz-meta-sha256", "x-amz-checksum-sha256"],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 3600
  }
]
```

上传失败提示会区分申请授权、上传清晰图、上传缩略图及服务端完整性校验。浏览器无法完成请求时，仍需检查CORS、网络和保存配置后的网页刷新；提示不能单独证明是哪一项配置有误。

同一张截图上传失败后，可以重新选择它重试。程序会自动恢复未完成的上传：压缩结果相同时沿用原上传状态并重新获取授权；结果变化时为这张截图换一组上传地址，旧授权不能把新尝试标记为完成。无需为重试删除存储配置或清空存储桶，已经保存的截图及其账目关联不会被替换。

如果提示「申请上传授权失败（409）」，请求还没有进入浏览器直传图片这一步，不能据此认定是R2跨域规则有误。界面会进一步区分存储设置变化、上传编号冲突或旧尝试已被新重试替代等原因，按具体提示重新选择截图或刷新网页即可；旧版程序仍提示旧上传状态冲突时，先更新程序。

更改存储来源后，已打开网页的权限策略仍可能使用旧配置，按界面提示保存输入并重新打开。已有凭证时不能随意更换桶/目录，避免图片失联；迁移需先复制图片并保持关联。

## 备份和速度

个人/整站加密备份包含账目、分类、回收站、每日状态、存储配置及图片索引。**图片本体仍在S3，不包含在 `.shendu` 文件里**，需要独立保管外部存储与密钥，数据库恢复不能找回已被外部删除的图片。恢复前会显示财务及凭证数量；旧备份没有财务部分时，保留仍属于同一账户的现有账本。

容量、请求费用及看图速度取决于S3服务、地区和网络。建议先用少量压缩截图测试；没有实际端点测试时不保证秒开。
