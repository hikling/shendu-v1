# 财务收支与压缩凭证

在顶部「财务收支」或 `/finance` 查看账本；新建每日复盘在睡眠、精力后显示「今天，花销多少？」。旧记录沿用原模板，不补造过去的花销。

## 逐行记下花销

每日花销题和财务页都使用大文本框，每行写金额或加减算式，空格后写用途，例如：

```text
60 打车
50 吃饭
```

下方实时显示两笔、合计 `110.00` 元，并建议交通、餐饮分类；每行分类都可以用下拉框修改。也可写 `8+8+8-1 早餐`，这一行合计 `23.00` 元。支持两位小数，一次最多30笔、6000个字符；空行会跳过，格式不完整的行会标出行号，修正后才能确认。输入和计算本身不会创建账目。

点击「确认入账」后逐笔保存。如果中途失败，已成功的行会从输入框移除，留下未完成的行供重试；不要重新抄回已成功的行。每日复盘保存草稿时会保留未确认的文字；旧版单笔草稿的金额、用途、分类、备注及凭证关联继续保留。

「详细录入」可设置日期、收支类型、分类和备注，也提供逐项填写多笔收支的入口。减号只用于金额算式，退款请使用「退款」并选择原支出，内部转账与还款使用「不计收支」。金额为人民币，精确到分。「收支差额」不是银行卡余额。

「确认入账」后独立保存到账本，删除复盘草稿不删除已入账账目。未确认的花销需先确认或清空才能进入下一题、提交复盘。暂时不记可跳过；「今天没有花销」与未记录区分。账目可补记、更正、移入回收站或恢复，分类可改名和停用。提交复盘后保留当时财务摘要，后续订正账本不改写锁定复盘。

## 按月查看收支

月份栏支持上个月、下个月和回到本月，也可打开月份面板选择年份与月份。打开面板、浏览年份不会重新读取账本，选定不同月份才更新数据。月份只决定查看范围；补记其他日期的账目请用「详细录入」。

左侧饼图显示所选整月的分类支出，右侧饼图显示某一天的分类支出，可用日历切换所选月内的日期。本月默认今天，其他月份默认最近有支出的日期或月末。饼图只按实际支出占比绘制；退款及净支出另行列出。分类金额和百分比同时提供文字列表；没有支出时显示空态。

收支明细按日期排列，搜索用途或备注、收支类型和分类筛选集中在明细上方。两张图和期间总计按完整期间计算，列表筛选及分页不改变它们。新记账的实际日期显示在输入区；补记其他日期请用详细录入。

## 截图记账

选择图片或在记账区域粘贴截图，先在当前设备压缩和识别。识别引擎及中文/英文语言包由本站提供，不调用云端识别。首次需要加载资源，手机速度取决于设备；处理过程中可取消。结果可能出错，必须核对日期、金额、类型和分类后入账。疑似重复项默认不勾选，可核对后保留；不同消费金额相同不会被自动删除。

每批最多20张，支持PNG、JPEG、WebP，限制文件大小和解码像素。长截图以文字可读为准，不承诺固定压缩率。**原图仅在设备内临时处理，不上传、不长期保存**；S3保留压缩清晰图和小缩略图，列表按需取缩略图，点击再取清晰图。未配置图片存储仍可本地识别和手填，但不会保存凭证，界面会提示。上传失败不能视为图片已保存。

## 私有S3设置

打开「图片存储设置」，可复用本人已有S3备份目标，或填写独立的服务地址、地区、桶、目录、访问密钥和路径风格。InfiniCLOUD的WebDAV备份继续可用，本版网页凭证直传采用S3接口。

桶保持私有。慎独按账户生成短时授权，浏览器直接与S3传输压缩图，慎独主机不保存图片。长期密钥只在服务端加密保存，不发送给网页。账目、图片仅本人可读；使用日志不显示金额、用途和截图内容。

存储须支持S3预签名PUT/GET、带SHA-256校验的上传，以及开启校验模式的HEAD读取，并配置CORS允许自己的网站，例如 `https://shendu.example.com`。允许PUT/GET/HEAD，请求头允许 `Content-Type`、`X-Amz-Meta-Sha256`、`X-Amz-Checksum-Sha256`。只返回自定义元数据、不能返回实际文件校验值的服务不会被视为上传成功。无需把桶公开。请在应用中填写密钥，不要发到聊天或公开代码。

更改存储来源后，已打开网页的权限策略仍可能使用旧配置，按界面提示保存输入并重新打开。已有凭证时不能随意更换桶/目录，避免图片失联；迁移需先复制图片并保持关联。

## 备份和速度

个人/整站加密备份包含账目、分类、回收站、每日状态、存储配置及图片索引。**图片本体仍在S3，不包含在 `.shendu` 文件里**，需要独立保管外部存储与密钥，数据库恢复不能找回已被外部删除的图片。恢复前会显示财务及凭证数量；旧备份没有财务部分时，保留仍属于同一账户的现有账本。

容量、请求费用及看图速度取决于S3服务、地区和网络。建议先用少量压缩截图测试；没有实际端点测试时不保证秒开。
