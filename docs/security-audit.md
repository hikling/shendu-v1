# 安全、备份与部署检查记录

检查日期：2026-11-06。范围覆盖生产服务端、浏览器模块与组件、备份工具、安装更新脚本、容器配置和锁定依赖。采用源码检查、隔离账户与文件测试、失败场景回归和独立交叉复核；没有访问运行站点的数据或密钥，也没有更改页面设计、插画和复盘内容。

## 本次修复

| 位置 | 原问题 | 修复结果 |
| --- | --- | --- |
| 登录限流 | 直接运行 Node 时可伪造转发 IP 绕过尝试次数限制 | 默认使用连接 IP；仅受保护的反向代理部署显式信任转发信息 |
| 外部备份 | 远端响应断连可能出现未处理错误；重复请求会同时保留大量备份数据 | 补齐响应错误/中断处理；每账户一个、全进程最多四个并发，手动操作另有频率限制 |
| 外部任务状态 | 忙碌拒绝可能覆盖正在执行任务的状态 | 返回明确忙碌状态，保留当前任务结果 |
| 网页导入、导出和登录 | 重复提交、过期文件读取或弹窗请求可能影响新的页面/账户上下文 | 请求绑定原页面、账户和弹窗；单次提交；失败保留输入并允许重试 |
| 行动验证 | 提交期间可取消、重复提交，迟到结果会关闭后来打开的页面/弹窗 | 提交期间阻止离开，结果仅更新原账户与弹窗；统计刷新失败不会误报验证未完成 |
| 命令行备份 | 错误输出路径可能覆盖数据库、SQLite 辅助文件、密钥或密码文件 | 解析目录别名并拒绝受保护目标 |
| 服务器快照密码 | 首次并发备份可能互相覆盖密码；脚本会改变密码文件中的换行 | 首次密码仅发布一次；保留原始密码文件字节；更新脚本共用同一实现 |
| 快照文件发布 | 复制失败可能留下名称正常但内容不完整的备份 | 在目标目录完成私有暂存后才发布；失败清理临时文件，保留原密码 |
| 容器与安装临时文件 | Caddy 接收到不需要的应用主密钥；中断安装可能残留含密钥的配置临时文件 | Caddy 只接收域名；临时配置排除在 Git 与镜像构建之外 |

## 重点验证的备份行为

- 个人备份的五种受支持格式继续保留；正确密码可恢复，错误密码、篡改和损坏文件会被拒绝。
- 检查跨账户归属确认、导入容量、重复记录、已完成记录保护、合并/替换及失败回滚。
- 整站网页恢复检查超级管理员权限和当前密码；成功恢复后旧会话失效。
- 命令行快照检查数据库完整性、密钥与加密字段、恢复失败时原文件保留；**命令行恢复仍须先停止应用**。
- 外部备份保留 HTTPS、DNS/IP 检查、地址固定、不跟随跳转、响应大小和超时边界。
- 安装/重跑检查原配置、数据库和密钥保留；选择更新前备份时，备份失败会在拉取代码、改动容器前停止。
