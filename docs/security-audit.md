## 2026-11-12—13 安全与逻辑复查

本轮覆盖账户、会话和权限、复盘生命周期、管理员操作、前端异步写入、日志可见范围、备份恢复、外部网络访问、部署脚本及锁定依赖。采用源码审查、隔离 HTTP/DOM/CLI 回归和独立交叉复核；没有读取线上数据库、主密钥或真实账户内容。

### 确认的问题与处理

| 位置 | 原问题 | 修复结果 |
| --- | --- | --- |
| 保存已有草稿 | 可通过接口改换类型或周期，把过期草稿移动到当前周期继续编辑 | 已保存记录的类型和周期不可变，冲突返回 409；原记录与日志不变 |
| 同周期新建复盘 | 重复创建普通复盘触发数据库唯一约束，返回通用 500 | 返回明确的 409 周期冲突；决策复盘仍允许同日多条；失败不留下记录或日志 |
| 管理员组合修改账户 | 多字段修改或撤销会话中途失败，前面已写入的部分不会回滚 | 账户字段、会话版本和会话删除在同一事务中提交或回滚 |
| 管理员弹窗与列表写入 | 重复提交可产生多次请求；旧请求迟到会关闭新弹窗或刷新其他页面 | 单次提交、等待期间保护弹窗；结果绑定原账户、页面和弹窗；旧请求不能解除新请求的忙碌状态 |
| 注册开关 | 保存失败后页面仍显示新值，与服务端实际开关不一致 | 请求期间禁止重复切换；失败恢复可见控件与原生控件的原值，允许重试 |
| 保存与完成复盘 | 强制更换账户或编辑器后，旧响应仍会覆盖当前记录与缓存 | 保存、提交及后续统计刷新绑定原账户、记录、编辑器和请求；成功锁定立即生效，统计或登录过期不能把它留在草稿状态；旧 401 不干扰新上下文 |
| 健康检查 | 数据库已为 schema 8，响应仍硬编码 schema 6 | 正常和缺少密钥两种状态均返回数据库实际版本 |

复盘保存的迟到响应问题通过强制替换上下文复现；日常导航本已有等待保护，本轮为额外的数据隔离加固，不代表已发现普通成员可以越权读取其他账户。服务端的归属、状态、周期和版本验证继续作为写入的最终边界。

## 本次修复

| 位置 | 原问题 | 修复结果 |
| --- | --- | --- |
| 登录限流 | 直接运行 Node 时可伪造转发 IP 绕过尝试次数限制 | 默认使用连接 IP；仅受保护的反向代理部署显式信任转发信息 |
| 外部备份 | 远端响应断连可能出现未处理错误；重复请求会同时保留大量备份数据 | 补齐响应错误/中断处理；每账户一个、全进程最多四个并发，手动操作另有频率限制 |
| 外部任务状态 | 忙碌拒绝可能覆盖正在执行任务的状态 | 返回明确忙碌状态，保留当前任务结果 |
| 网页导入、导出和登录 | 重复提交、过期文件读取或弹窗请求可能影响新的页面/账户上下文 | 请求绑定原页面、账户和弹窗；单次提交；失败保留输入并允许重试 |
| 行动验证 | 提交期间可取消、重复提交，迟到结果会关闭后来打开的页面/弹窗 | 提交期间阻止离开，结果仅更新原账户与弹窗；统计刷新失败不会误报验证未完成 |
| 命令行备份 | 错误输出路径可能覆盖数据库、SQLite 辅助文件、密钥或密码文件 | 解析目录别名并拒绝受保护目标 |
| 服务器快照密码 | 首次并发备份可能互相覆盖密码；脚本会改变密码文件中的换行 | 首次密码仅发布一次；保留原始密码文件字节；更新脚本共用同一实现 |
| 快照文件发布 | 复制失败可能留下名称正常但内容不完整的备份 | 在目标目录完成私有暂存后才发布；失败清理临时文件，保留原密码 |
| 容器与安装临时文件 | Caddy 接收到不需要的应用主密钥；中断安装可能残留含密钥的配置临时文件 | Caddy 只接收域名；临时配置排除在 Git 与镜像构建之外 |
