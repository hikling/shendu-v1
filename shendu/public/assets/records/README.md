人物细曲线、象牙白、夸张长肢体与少量平面填色对照项目既有[概览图标](../overview/README.md)。新图重新生成独立姿态、道具与构图，不复制原图构图，不将原图重新声明为生成作品。

原始请求为1024×1024、medium质量、暖白背景；服务实际输出65张1254×1254 RGB PNG。此目录为本地处理后的640×640透明WebP：只提取与画布外缘相连的暖白背景，保留封闭纸形与人物内部；按对应类别调色板统一平面填色与轮廓，再缩放留边。透明来自本地处理，**不是模型原生透明**。原始PNG保持不变。

`manifest.json` 保存每张的类别、关键词、源文件／发布文件SHA256、真实尺寸和处理参数。原始PNG、六类联系图与完整图册在[输出目录](../../../../output/imagegen/record-library/)，提示词、逐图审阅与复现命令在[生成说明](../../../../art/record-library/README.md)。不包含密钥、服务地址或账户信息。

`record-art.js` 为历史和行动验证共用同一图池：先从全量记录计算配图，再筛选／分组；同类用完一轮才复用，优先匹配本地关键词，未命中按ID稳定分配。图片不接收点击或焦点，不新增记录字段。概览轮播与六类填写画布继续使用各自素材。网站部署与运行不需要生成服务或API密钥。
