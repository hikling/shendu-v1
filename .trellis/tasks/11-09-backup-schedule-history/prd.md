# 外部备份设置与记录

1. S3字段标签、提示与相关错误使用中文（协议名与真实配置值保留）；每天选择具体时分，每周选择星期及具体时分，统一北京时间；目标列表显示完整计划。
2. 最近运行记录仅展示最近十个北京时间自然日的真实备份成功/失败，显示目标名称、存储类型和手动/定时来源，不再记连接测试；不再截断为12条。现有已知测试日志不展示。
3. 行动验证的原定行动标题在上、完整内容在下，与结果和调整阅读方式一致；桌面/手机均适用。
4. 编辑保留目标的非敏感设置但连接凭据重新输入；保留失败输入、重复提交防护、账户隔离和外部HTTPS/DNS/限流/加密边界。
5. 兼容旧数据库和整站备份。默认已有定时目标采用每天/每周一02:00（北京时间），页面明确展示，可修改。手动备份和测试不改变定时执行槽位；定时失败每个计划槽只记录一次，不按分钟重试。
