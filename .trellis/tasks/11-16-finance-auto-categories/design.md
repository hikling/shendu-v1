# Design
Root owns public/finance-domain.js keyword enrichment, finance-ledger.mjs confirmed-entry automatic categories and transaction/idempotency/backup tests. Unknown purposes use complete purpose as category name (160 chars), encrypted existing category table, random UUID, reused by exact decrypted name per account; create only inside successful entry transaction. Existing explicit category IDs keep compatibility, category count cap becomes entry cap50000 plus built-in count so automatic fallback is not blocked after89 unknown purposes. Name bound for imports expands160 for generated categories. Existing category API remains for backups/compatibility; remove UI manager only.
UI worker owns finance-ui.js, finance.css, finance-ui tests and dialog layout. Existing suggestFinanceCategory returns uncategorized for unknown; exported financeCategoryLabel(purpose,categories,kind) returns suggested category name or trimmed complete purpose (up to160). For automatic new entries send categoryId empty, server owns resolution; preserve explicit/manual legacy IDs and partial retry identity. UI displays automatic label; quick preview must not show generic uncategorized for unknown. Root owns domain cache and app/index token changes/docs. UI must coordinate precise payload contract.
Screenshots remain private receipts attached to confirmed entries. Improve visible per-entry screenshot count/view triggers, preserve original preview private signing/error/retry and thumb lazy load. No server gallery or unassociated-receipt endpoint.
