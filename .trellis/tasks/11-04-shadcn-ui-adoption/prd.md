# 全站 shadcn/ui 采用

## User request
网站全部UI在适用的地方使用 https://github.com/shadcn-ui/ui 的真实组件。

## Outcomes
- 采用官方组件源码和React运行依赖，建立可维护的统一UI层，不是只复制样式或改类名冒充组件。
- 通用按钮、表单、选择、标签、卡片、表格、反馈、菜单、弹窗、分页／面板切换、日历等逐一核实适用性并接入；不适用项记录具体原因。
- 保留现有慎独品牌、宋体、六类配色、插画、概览弧形连续轮播和沉浸式复盘构图。
- 全站涉及登录/注册、概览、六类复盘、阶段日历、历史、行动验证、设置/账户、备份、管理员页面及确认/错误状态。
- 复盘数据、加密、权限、备份、验证等待规则和API不变；刚修好的列表返回、筛选、焦点与滚动恢复不可回退。
- 本地构建和Docker部署均可复现；更新README安装/运行步骤，实际构建与浏览器验证后提交同步main。

## Acceptance
- 项目中存在可追溯的真实shadcn组件源码、依赖锁文件、配置与组件覆盖表；浏览器加载构建产物，无远程CDN运行依赖。
- 所有可迁移控件在真实页面使用组件；业务特有图像、motion path、自绘画布不被生硬替换成普通Carousel或卡片。
- 全部六类填写：当前/历史只读、首存、切题、答案增删折叠、日期选择、草稿保存、完成锁定、未保存退出、错误重试正常；收起题目数据不丢失。
- 账户隔离、脱敏、无正文外发、备份导入预览/恢复、管理员操作与server保持原契约。
- 弹层打开关闭、焦点约束/恢复、键盘、屏幕阅读、320/390/820/1280px、减少动态、自定义白色主题、长内容和空/错误状态通过。
- npm ci/build/check/test通过；干净环境Docker构建与/healthz及前端构建资源检查通过（无法本机构建时明确用CI核实）。
