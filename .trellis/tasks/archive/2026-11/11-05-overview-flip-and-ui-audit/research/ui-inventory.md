# 全站页面与弹层清单

审计依据：`public/app.js` 的 `navigate()`、全部 `render*` / `open*` 入口及 `openModal()` 调用。此清单区分已经统一的表面与本任务补齐的遗留表面；不改数据、权限或记录生命周期。

| 表面 / 入口 | 审计前状态 | 本任务处理与行为边界 |
| --- | --- | --- |
| 登录、注册、首次管理员 / `renderAuth` | 旧深绿分屏、金色内框，无相关插画 | 改为象牙纸面、粗宋体、本地阅读场景；保留所有字段约束、注册开关、显示密码与全量退出清理 |
| 启动加载 / `boot` | 通用大骨架卡片 | 同一纸面插画与实际加载提示；请求与成功路由不变 |
| 启动加载失败 / `boot` catch | 旧通用卡片 | 同一错误纸面，保留原错误转义、401回到init与重试闭包 |
| 初始连接失败 / `init` catch | 旧通用卡片 | 同一错误纸面，保留原重新加载绑定 |
| 概览 / `renderOverview` | 已统一，入口仍有侧向信息 | 主会话负责原位翻面；轮播和主句保留 |
| 日 / 周 / 月 / 季 / 年 / 决策 / `renderReview` | 已统一的沉浸画布、独立插画与逐题输入 | 保留全部六类场景、输入、锁定、保存与返回来源 |
| 历史复盘 / `renderHistory` | 已统一的宽归档、插画卡片 | 保留近期完成排版及搜索、筛选、真实记录打开 |
| 行动验证列表 / `renderActions` | 已统一，含大插画和紧凑日期 | 保留大插画、单一阅读面和真实验证资格 |
| 数据备份及异步失败 / `renderBackup` | 已统一工作区与可重试错误 | 保留加密、角色、导入导出和失败重试 |
| 账户管理 / `renderUsers` | 已统一工作区和响应表格 | 保留权限、注册开关、搜索和所有账户动作 |
| 设置入口 / `openSettings` | 已统一的插画菜单 | 设置实现者删除设色入口、独立保留减少动态 |
| 账户与安全 / `openAccount` | 已统一的插画标题与双分区 | 保留密码要求、未保存退出阻挡及登录重置 |
| 阶段与内容设置 / `openStage` | 已统一的插画标题与折叠内容 | 保留阶段、模板快照、开关和全部保存逻辑 |
| 使用指南 / `openGuide` | 已统一的插画标题与纸面正文 | 保留原文与层级 |
| 主题 / `openTheme` | 已统一视觉，但功能待移除 | 设置实现者移除颜色功能，兼容已存主题数据 |
| 阶段与日历 / `setRailOverlayOpen` | 已统一的真实Dialog / Tabs / Calendar | 保留固定壳、内部页面、键盘与嵌套焦点；无六类侧卡 |
| 重新认证 / `sessionExpired` | 旧无插画通用表单 | 静态夜读图、纸面输入和宋体标题；持久不可关闭、原编辑器与未保存内容继续保留 |
| 完成锁定 / `completeCurrent` | 旧通用确认 | 通用纸面、相关记录插画、清晰锁定摘要；busy和不可修改语义不变 |
| 未保存离开 / `attemptNavigate` | 旧通用确认 | 同通用纸面；继续填写 / 放弃修改的原绑定不变 |
| 个人备份恢复确认 / `bindBackupControls` | 旧通用确认，含跨账户验证字段 | 同通用纸面与表单边界；原密码、归属、模式和实际恢复不变 |
| 验证结果 / `openVerification` | 已统一的类别插画、计划和原生表单 | 明确排除通用覆盖，保留其独立配色与日期/结果约束 |
| 备份密码、个人恢复密码 / 对应form ID | 已有专属工作区操作样式 | 明确排除通用覆盖；保留密码最小长度、自动填充与提交 |
| 整站导出、校验、恢复 / site form IDs | 已有专属工作区操作样式 | 明确排除通用覆盖；保留超级管理员认证及不可逆提醒 |
| 外部备份新增/编辑 / `openTargetModal` | 已有专属工作区操作样式 | 明确排除通用覆盖；保留HTTPS约束及凭据字段 |
| 用户创建、重置、删除 / user form IDs | 已有专属工作区操作样式 | 明确排除通用覆盖；保留角色、二次认证与永久删除确认 |
| 顶部账户/移动菜单 / `bindHeaderMenus` | 已统一的真实DropdownMenu | 保留无色块文字交互和焦点返回 |
| Toast、保存失败、版本冲突 / `toast`, `saveCurrent` | 已统一的Sonner；版本冲突没有独立弹框 | 沿用真实通知，不新增阻塞弹框或改变刷新策略 |
| 外部备份目标删除 / `bindBackup` | 浏览器系统确认 | 已换为同族Radix确认；明确确认才DELETE、取消/Esc无请求、失败可重试、关闭返回原删除按钮；远端文件不会删除的提示保留 |
| 离站未保存警告 / `beforeunload` | 浏览器安全表面 | 必须沿用浏览器控制，不能用自绘弹层替代 |

通用覆盖仅由 `openModal` 根据显式surface类与已定制操作form识别，不触碰已经统一的Dialog布局。所有新插画仅使用已有本地资源，`aria-hidden`、空alt、固定尺寸、无指针与焦点行为。
