# 六类翻面入口与全站界面统一

## 目标
- 删除主题颜色功能及所有入口，保留默认产品配色、六类独立配色和减少动态偏好。
- 概览六类入口取消左右展开信息，只在原卡片背面显示简短类别名称；悬停／键盘聚焦时翻面，单击直接进入原复盘。
- 审查所有页面与弹层，将仍使用旧风格的表面统一为已确定的纸面、宋体、低饱和配色与相关本地插画风格。

## 验收
1. 设置不再出现主题、色板、颜色字段或对应子框；减少动态仍可独立保存，旧备份主题数据兼容且不被清空。
2. 六类入口保留原图标、尺寸、颜色、桌面一行；背面只显示类别名，无时长／用途／进入按钮／左右浮层，悬停及聚焦翻面且其他入口不位移。鼠标／键盘／触屏仍直接导航。
3. 减少动态时无3D旋转，但类别内容仍可见；六入口全区域命中正常，无伪元素遮挡、重叠或窄屏横向溢出。轮播逻辑不变。
4. 用页面与弹层清单记录审查结果，实际修正遗留登录／注册、通用提示、重新认证等表面；已更新界面保留布局与数据行为。
5. 原权限、备份、表单约束、保存／锁定、未保存保护、返回来源、焦点隔离继续有效。
6. 生产构建、语法、必要回归、资源烟测、桌面与320/390/820px浏览器验收通过，README／规范／截图同步，提交main并核对CI。
