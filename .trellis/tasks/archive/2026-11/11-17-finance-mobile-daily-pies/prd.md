# 财务手机导入、分类与日月明细

## Requirements
- 修复手机截图核对弹窗日期控件突出卡片，320/390px下日期、类型、金额、用途、分类等字段完整可读。
- 扩大自动分类：买东西及日常购物表述归购物，买面条等常见食物归餐饮，补充更多生活用途；具体用途优先，未知用途仍沿用用途名称，手动指定及旧账保留。
- 收支明细提供按整月／按单日查看，单日可选日期。保留搜索、类型、已删除、分页和输入草稿；明细选择不改变上方整月统计及月／日饼图语义。
- 饼图采用更明亮配色、圆润分区与适度视觉过渡，保留真实数据占比、分类颜色稳定、文字图例和退款含义；减少动态设置生效。
- 使用现有组件库和中文宋体体系，完成自动检查与桌面／窄屏验收，按已授权流程同步main并验证发布。

## Acceptance
- [x] 手机导入日期与所有控件没有横向溢出。
- [x] 分类词库及所有输入模式一致，买东西／买面条等实际例子与旧分类兼容通过测试。
- [x] 日月明细、选日期、筛选分页与请求竞态正确，月统计不随明细变成日统计。
- [x] 饼图视觉更轻快，空态、图例、稳定分类色与减少动态可用。
- [x] 构建、相关及全量测试、浏览器检查通过；GitHub同步与发布通过。
