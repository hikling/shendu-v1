# 概览类别配色与入口文字层级

## 目标

周、月、90 天复盘的九张阶段插画，应分别与概览的周、月、季图标使用同一人物画风和类别调色。六类入口悬浮信息卡的标题、说明、时长与按钮建立清楚的字号、字重和颜色层级；六类复盘内部的题目标题同步放大，并区分题目、说明和辅助文字。

## 改动边界

差距位于 `public/assets/extended/` 的九张插画和 `public/styles.css` 的 `.overview-type-info` 文字样式。周图标以珊瑚粉、暖棕为主；月图标以琥珀、深棕为主；季图标以湖蓝、深蓝为主。保留九个场景各自的道具与动作、透明背景和阶段资源名称。概览六个图标、入口排布、展开方向、导航和轮播沿用现有行为。每日、年、重大决策仅调整共用的题目文字层级，不修改插画和布局。

## 验收

- [x] 九张阶段插画与对应概览图标的笔触、人物形态和主要色调一致；周无大面积绿色、月无大面积青绿、季无大面积青绿。
- [x] 九张场景语义仍各不相同，透明背景与页面裁切正常；PNG、WebP、提示词及哈希同步。
- [x] 六类展开信息卡的标题显著大于说明，主次文字与类别色对比清晰；桌面及手机不溢出，键盘焦点和点击跳转正常。
- [x] 运行语法与适用测试，完成页面验收、文档更新并同步仓库。

- [x] 六类内部题目采用更大的粗宋体，说明和状态的尺寸、字重与颜色形成清楚层级；保留原问题、表单和保存验证规则。
