# Design and ownership

Routing gap: app only has in-memory route names; server already returns index.html for nonAPI GET. Route worker owns app.js navigation integration, browser-navigation.js and relevant navigation/auth/write/deeplink tests. Use paths /history,/finance etc and /review/UUID. Metadata only in history:route/ID/period/scroll, never answers/search/finance data. Preserve review navigator, dirty/save/account guards. Handle popstate with indexed history recovery before confirmation; don't destroy forward with push-on-cancel. Save upgrades URL with replace without remount. No question history.

Finance worker owns finance-ledger.mjs aggregate fields, finance-ui.js/finance.css, shadcn chart/Recharts helper/components/dependencies and finance tests. Add positive expenseCategoryTotals for all active expenses in selected period, independent of filters/pagination. Keep net aggregate compatibility. Daily data query has independent async owner and refreshes after mutation. Use genuine shadcn Chart + Recharts Pie; text legend and refund/net text. No handcrafted CSS pie. Root owns month/day controls in ui/finance-period.jsx/css, compact shadcn Select variant in ui/runtime.jsx/components/ui/select.jsx, exports/control tests, docs/cache/task.

Root API: showFinanceDayPicker(host,{value,month,today,isCurrent,onChange})->{setValue,setMonth,setDisabled,dispose}. It uses existing civil Calendar and a genuine Radix/shadcn surface, no callback on browse/close; date constrained within month. Route worker imports/injects it in financeUiOptions. Finance worker mounts picker and owns selected-day loading. Root converts data-finance-compact select to actual shadcn Select retaining original hidden select values/events/FormData. No forced redesign elsewhere.

Visual: light text-led month row and compact Select triggers, SVG chevrons; same paper tokens and ink, two restrained equal-width pie panels (stack on mobile), nearby visible legends. No DB migration. Business decisions resolved by user clarification and explicit library constraint.
