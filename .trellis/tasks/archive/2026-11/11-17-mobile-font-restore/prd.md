# 恢复手机菜单宋体字体

## Goal

撤回上一轮手机菜单黑体字体指定，恢复原宋体，仅修字体并保留已完成菜单排版交互与桌面

## Requirements

- 恢复上一轮被改成黑体的手机菜单标题及条目，沿用原有宋体风格。
- 只修正手机字体；保留菜单排版、字号、行高、点击行为和箭头效果。
- 不调整桌面界面及其他页面原有字体。
- 构建资源及缓存版本同步更新，避免旧字体样式继续命中缓存。

## Acceptance Criteria

- [x] 手机菜单面板、标题和条目沿用原有宋体，不再被黑体声明覆盖。
- [x] 变更仅在原手机断点生效，其他排版与交互保持不变。
- [x] 构建、语法检查及现有菜单自动测试通过。
- [x] 已同步 GitHub main，并明确记录未进行手机浏览器实测。
