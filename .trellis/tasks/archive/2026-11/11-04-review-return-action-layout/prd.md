# 复盘返回来源与行动阅读排版

## Requirements
- 历史列表打开任一类记录，退出复盘回到历史列表，保留筛选；从行动列表进入也应返回行动列表。概览进入仍返回概览。
- 退出继续遵守未保存修改确认、保存中禁止离开和只读记录规则。
- 删除行动页的候、验装饰章（分区和卡片），保留真正的类别和状态信息。
- 重新组织行动卡片的计划、结果和调整，消除不等高的双框及重复标题。保留原文、时间、状态、验证入口及图片。
- 完成后提交并推送main。

## Acceptance
- 六类历史/行动记录退出回到各自来源，重新进入不继承错误来源；筛选和长列表位置合理恢复。
- 草稿取消离开保留原输入，放弃后返回来源；保存重绘不丢来源。
- 行动内容在桌面/390px/320px、长短文本/空旧字段下不溢出、不截掉正文、无候验装饰。
- npm run check、npm test、diff检查和真实浏览器验收通过。
