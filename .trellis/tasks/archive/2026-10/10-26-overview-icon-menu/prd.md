# 概览图标入口与长卷上移

## Goal

参考用户指定的 Coffee options 动效，将六类入口改为紧凑图标菜单，并删去长卷标题和多余留白。

## Requirements

- 六个入口的方框只显示各自的图标，缩小入口占用。
- 用户已确认：鼠标悬停或键盘聚焦时，在图标左侧展开类别名称；单击或 Enter 直接进入对应页面。
- 使用项目现有语义 SVG 图标和配色，增加与参考相似的弹性反馈，减少动态效果时仍显示名称。
- 删除「回看长卷」「已经写下的记录」，空状态也不保留同名标签。
- 弧形滚动记录整体上移；记录筛选、循环和原记录跳转保持可用。

## Acceptance Criteria

- [x] 默认只见六个小图标方块，悬停/聚焦向左展开正确名称，六类均可一次点击进入。
- [x] 窄屏、键盘和减少动态效果下可用，无标签裁切、卡片重叠或页面横向溢出。
- [x] 两处指定标题均消失，实际测量长卷比旧版更靠上，弧形循环仍有效。
- [x] 语法、实页检查通过；静态资源缓存版本、README 预览图和设计规范同步。

## Change boundary

只调整概览模板和局部 CSS、弧线顶部偏移及入口缓存版本；复用现有 `NAV_ICON_PATHS` 和 `data-nav` 导航绑定。其他页面、后端和记录数据规则不变。
