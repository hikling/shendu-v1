# 每日复盘交错构图与语义插画

## Goal
保留用户接受的艺术风，解决图文始终同向、插画语义弱、输入区难辨识和品牌漂移四项反馈。

## Requirements
- 01证据插画右/内容左；02事实与原因插画左/内容右；03行动插画右；04日记插画左。引导保留艺术开场。
- 插画与当前问题明确关联，使用接近六类入口的彩色、细线、人物/纸品构图；用户允许原创绘制。替换抽象墨形和巨型单字为真实语义场景。
- 输入区有清晰边界/底色/内边距和焦点；数字、文字、状态、日期都可辨认为控件。
- 左上角恢复概览已有红色印章及宋体慎獨字样，不再使用每日专属变体。
- 保留单题、打字机、保存、dirty/busy/失败/401保护、模板与只读；其他五类和概览功能不重做。

## Acceptance
- [x] 四组左右交错，真实截图可见；窄屏保持内容顺序和无横向溢出。
- [x] 插画语义可辨、风格协调，原创本地资源有说明，无远程依赖。
- [x] 所有输入有清楚容器/占位/焦点，数值100/10可完整输入。
- [x] 每日与概览品牌一致；直接退出继续受dirty保护。
- [x] 保留表单行为，检查/测试及视觉QA完成，README/规范/截图同步并推送。
