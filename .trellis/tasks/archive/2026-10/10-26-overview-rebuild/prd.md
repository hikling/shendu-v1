# 重做概览与顶部导航

## Goal

让个人使用者登录「慎独」后，首先看到一个可进入六类复盘、可回看已完成记录的概览页。以用户提供的 ClassDojo 截图作为构图与动效参考，为「慎独」建立自己的视觉语言，并把现有左侧入口迁至顶部。第一阶段保持其他页面的主体内容、记录规则和数据安全行为。

## Background and confirmed facts

- 当前仓库基线是 `codex/restore-original-ui` 的 `60434e3`，工作区在任务创建前为干净状态；此分支比 `origin/main` 多三个提交。用户确认以当前分支为新版本基础。
- 前端是无构建工具的原生单页应用。`shendu/public/app.js:136-150` 生成侧栏、顶部栏与共享外壳；`navigate()` 和 `boot()` 在 `:420-423`，目前登录后进入每日复盘。
- 六类复盘由 `shendu/public/app.js:5-12` 定义。现有左侧入口另有历史复盘、行动验证、数据备份、管理员账户管理，账户设置由侧栏底部卡片打开（`:136-146`）。
- `refreshData()` 已取得当前登录用户的记录（`shendu/public/app.js:422`）；`GET /api/records` 按登录用户过滤，并返回解密后的记录（`shendu/server.mjs:1200-1208`）。记录状态为 `draft`、`completed`、`verified`（`shendu/public/app.js:27`）。现有记录没有图片字段。
- 现有主句是「言寡尤，行寡悔，慎独存诚」（`shendu/public/app.js:123,138`）。

## Requirements

| ID | Requirement |
| --- | --- |
| R1 | 登录成功后默认进入新的概览页；未登录者不能看到概览或私人复盘内容。 |
| R2 | 概览采用参考图的顶部导航、居中主句、六张分类入口卡和底部横向移动内容区。主句使用「言寡尤，行寡悔，慎独存诚」；整体颜色、字体与图标属于「慎独」，不复制 ClassDojo 品牌。 |
| R3 | 六张入口卡分别进入每日、每周、每月、90 天、年度与重大决策复盘。即使旧导航的 90 天入口由阶段设置隐藏，概览仍提供六类入口。 |
| R4 | 登录后所有页面使用顶部导航：概览、历史复盘、行动验证为直接入口；复盘分类置于“复盘”菜单；账户、备份、设置置于右上角用户菜单。管理员账户管理仍按原有权限显示。手机端能使用同一组入口。顶部菜单中的 90 天入口继续受现有 `showQuarter` 开关控制，概览六张卡不受该开关控制；阶段设置仅更新这项开关的说明文案。 |
| R5 | 底部内容从当前用户六类记录中的 `completed` 和 `verified` 状态随机选取与排序，持续横向循环移动。每张卡显示类别、日期、标题及短摘录；点击进入原记录。草稿不得出现。没有符合条件的记录时显示开始复盘的引导。 |
| R6 | 概览与顶部导航支持键盘、手机与窄屏；系统和用户设置的减少动态效果会停止自动移动，同时保持内容可访问。 |
| R7 | 第一阶段不改其他页面的专属渲染、表单流程、复盘生命周期、后端 API、数据库、加密及备份。仅共享外壳、导航和必要样式可以影响其他页面；原有入口、未保存提醒和权限行为保持可用。 |
| R8 | 概览完成并验证后，创建私有 GitHub 仓库 `hikling/shendu-v1`，以当前分支代码为基础建立新的 Git 历史；保留原仓库。迁入新仓库前检查提交内容，不包含本地密钥、数据库或备份。 |

## Acceptance criteria

- [ ] AC1 (R1): 登录后打开概览；退出或未登录时只见原有认证流程，不能通过概览读取个人记录。
- [ ] AC2 (R2, R3): 宽屏首屏具有顶部导航、主句和六张可用的复盘入口；手机上六类仍完整可达，页面没有横向溢出。主句为确认的原文，视觉不含参考品牌标识或文案。
- [ ] AC3 (R4, R7): 从概览与每个旧页面都能经顶部导航到达历史、行动验证、备份、账户设置以及授权用户可见的账户管理；顶部“复盘”菜单保留当前五类或开启开关后的六类入口，概览始终能进入全部六类。当前入口状态明确。旧页面的专属主体与表单行为保持原样，未保存编辑时切换页面仍会提醒。
- [ ] AC4 (R5): 仅当前账户的 `completed`/`verified` 记录进入移动卡片；草稿不出现。卡片显示经过长度限制和 HTML 转义的标题、短摘录与类别/日期；点击打开匹配的原记录。空数据时有可操作引导。
- [ ] AC5 (R5, R6): 多条记录时移动连续、循环且无明显跳帧；悬停、键盘焦点或可见的暂停控制都能停止移动，控制可再次启动。系统或用户启用减少动态效果时自动移动停止，记录仍可浏览和打开。
- [ ] AC6 (R6, R7): 桌面与窄屏实际页面、键盘导航、菜单开合、主题预设和自定义颜色经过检查；`shendu/` 下 `npm run check` 通过。如实施触及服务端或数据契约，`npm test` 也通过。
- [ ] AC7 (R8): 概览通过验收后，`hikling/shendu-v1` 是私有独立仓库，包含本阶段成果与新 Git 历史；原 `Shendu` 仓库未被覆盖，提交不含本地密钥、数据库和备份文件。

## Out of scope

- 重做其他复盘页面、历史、行动验证、备份、账户管理或登录页的主体界面。
- 自动保存、记录编辑与完成规则、数据结构、备份格式或服务器部署方式变更。
- 为复盘新增图片上传或生成配图；底部采用真实复盘文字卡。
- 后续阶段的全站 UI 与代码重构；它们在概览验收后分别规划。
