# 历史记录插画计数与全站操作流水

## Goal

内置绘图生成与动态记录数融合的历史插画，日志改为跨日期流水，管理员全站可见、成员仅本人，保留分页与隐私边界

## Requirements

- 内置 image_gen 生成新插画，记录数量融入右侧书页画面，不再与左侧按钮并排；保留真实精确数量，支持0、三四位及更大数值，读屏可读。
- 日志默认直接列出跨日期操作，按北京时间日期分组，显示时分、操作人及操作名称和必要类型/周期，不先选一天。
- 用户明确：管理员可查看全站操作，普通成员只能查看本人；服务端控制权限与游标范围，不能读取他人正文或凭据。
- 保留分页、空态、加载/失败重试、过期页面/账户保护；只记录真实事件，不补造历史操作。
- 验证后沿用既有授权同步 GitHub main。

## Acceptance Criteria

- [x] 数量与插画自然融合，长数字不溢出，其他复盘布局与筛选不变。
- [x] 日志打开即显示跨日期流水，日期/时间/操作人/行为明确。
- [x] 管理员全站与成员本人边界有接口回归验证，分页/失败/过期响应有UI验证。

## Notes

- 管理员可见全站操作为用户本轮明确确认；固定元数据隐私保持。
