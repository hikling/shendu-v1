# 每日复盘逐题沉浸填写与打字引导

## Goal

放大引导文字并增加打字机效果，填写阶段隐藏导航，睡眠、精力、指标和02/03各问题分屏依次呈现。

## Requirements

- 引导文字明显放大，以简洁、有层次的中文排版呈现，并逐字出现；减少动态效果时直接显示全文，屏幕阅读器一次读全文。按钮随时可进入。
- 开始填写01—04后隐藏顶部导航并移除其空间/焦点；保留小型退出入口、上一步、下一步与手动保存。
- 01依次显示昨夜睡眠、精力、每一项阶段指标、风险；02事实/原因分别一屏；03行动/阻碍/应对/验证日期分别一屏；04日记。每屏仅一个问题，阶段仍归属01—04。
- 返回、增删答案、保存与错误重试保留所有输入和当前题；只校验当前题原本必填项，原可选项不新增必填。
- 完成锁定、历史只读、模板快照、未保存离开保护不变；其余五类与概览不调整。

## Acceptance Criteria

- [x] 引导大字与打字机效果稳定，无布局跳动或逐字读屏干扰，减少动态效果显示全文。
- [x] 填写期间顶部菜单不可见不可聚焦，退出/回引导/切到其他页面正确恢复导航。
- [x] 睡眠、精力、各指标、02两问和03各字段逐题呈现，前后切换保留数据，校验定位正确。
- [x] 历史记录可完整查阅，完成入口/验证内容可达；网络失败/慢请求保护沿用。
- [x] 桌面/手机及键盘验证，测试/检查通过；文档截图同步，提交推送。

## Notes

- Keep `prd.md` focused on requirements, constraints, and acceptance criteria.
- Lightweight tasks can remain PRD-only.
- For complex tasks, add `design.md` for technical design and `implement.md` for execution planning before `task.py start`.
