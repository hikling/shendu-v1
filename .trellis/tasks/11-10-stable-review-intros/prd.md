# 固定历史复盘引导与局部位置调整

## Goal

已保存复盘首页文案按记录固定，历史插画略上移，概览标题说明及六类入口下移但不移动轮播

## Requirements

- 历史页书册整体略上移，数字与单位随画面一起移动，保持标题已对齐的位置。
- 每条已保存复盘（草稿、已完成、已验证）的引导首页固定相同文案，反复进入、重载、不同入口不再抽随机语句；六类均适用。
- 概览标题、说明及六类入口整体向下微调，轮播位置、路径、节奏不变。
- 不改变记录内容、状态、模板、验证规则或备份格式，完成后按既有授权同步main。

## Acceptance Criteria

- [x] 已保存记录跨次进入文案稳定，新建/未保存引导与离开保护正常。
- [x] 历史插画上移且计数随图，概览上半区下移但轮播布局不动。
- [ ] 检查/测试通过，浏览器可用时核对实际桌面手机布局。
