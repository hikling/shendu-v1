# 把周月季年与决策复盘延续为沉浸式页面

## 目标

把每日复盘已经确认的艺术画布、清楚的文字层级和逐题书写节奏延续到其余五类复盘。周、月、90 天、年、重大决策各有自己的语义和视觉强调，不复制一模一样的页面。

## 本轮范围

- 五类复盘都有简短引导、明确的开始入口、单题书写、上一题/下一题、草稿保存和最终完成入口。每个问题仍使用本类原有文案、可自定义模板及必填规则；长答案仍支持最多五条。
- 决策名称、各类问题、接下来的行动、阻碍预案和验证日期均可完整填写与回看。原有草稿、历史只读、完成锁定、行动验证、脏数据离开保护及账户隔离不变。
- 沿用每日复盘的雾蓝纸面、加厚宋体标题、深色主句与类别色重点、蓝灰说明、静态纸形与细线陪衬。不同类别使用对应的独立强调色和不同的临时类别插画；桌面左右交错，手机上不遮挡输入。
- 本轮不调用未提供的图像生成工具，不冒充已经生成了新插画。用户确认先完成页面、稍后补插画；暂用项目已有且五类各不相同的类别插画，留好后续 `imagegen` 专属场景的替换位置与艺术方向说明。
- 已确认的概览、每日复盘、其他记录页面和后端数据格式保持现有行为。

## 验收

- [x] 五类入口均进入新引导与逐题画布，每类问题顺序完整且一屏聚焦一个问题；决策名称和最终行动/预案/日期没有遗漏。
- [x] 必填问题在当前屏提示并定位，选填问题可跳过；增删答案不丢失内容或跳回开头；保存后保持位置，最终锁定与验证规则不变。
- [x] 已完成/历史记录可按同样节奏只读浏览，原有模板快照与结果回看完整；离开未保存内容仍有保护。
- [x] 桌面、390px 和 320px 下标题、输入和装饰不重叠、无横向溢出；键盘焦点、主题和减少动态效果可用。
- [x] 五类临时插画彼此不同并明确标注待生成；没有把每日插画挪作新类别插画。README、设计文档、Trellis 前端规范和页面截图与本轮状态一致。
- [ ] 语法、相关测试和完整 CI 通过；提交、同步仓库并归档 Trellis 任务。
