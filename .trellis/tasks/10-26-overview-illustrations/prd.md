# 六类彩色插画与提示卡优化

## Goal

采用用户指定合集的合适插画，为六类入口配色并加入时间标记，放大入口、改善右侧信息提示，同时修复长卷空白区误暂停。

## Requirements

- 从 Iconfont 合集 52510 选六张语义合适的原始插画，保留实际构图，分别配色和添加「日、周、月、季、年、决」。
- 比现有 64px 图标更大，保持六类入口可辨认；屏幕阅读器保留完整名称。
- 悬停/键盘聚焦在右侧展开有层次的信息卡，包含类别、用途和预计时间；单击直接进入，Escape 可关闭提示。窄屏提示不得被裁切或产生文档横向溢出。
- 只有鼠标位于真实复盘卡片上才暂停长卷；停在卡片外的空白处或六类入口下方仍继续移动。键盘阅读与减少动态效果保留。
- 同步设计规范、来源说明、资源缓存版本和 README 预览。

## Acceptance Criteria

- [x] 六张插画来自指定合集并与类别语义匹配，彩色且带六种标记，入口放大。
- [x] 右侧信息卡有完整层次，桌面和窄屏不裁切；点击和键盘进入六类正常，Escape 关闭提示。
- [x] 空白区域悬停时持续运动，真实卡片悬停时暂停且移出后恢复。
- [x] 静态资源、设计文档与来源说明同步；语法、响应式和浏览器回归检查通过。
