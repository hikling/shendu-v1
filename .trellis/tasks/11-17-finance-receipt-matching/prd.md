# 收入专用录入与支出截图匹配

## Requirements
- 详细录入改为收入记账，仅创建income，不显示无法点击的收支类型选择，也不能带入/消耗待记支出文本。
- 财务页和每日复盘共享花销输入：保留逐行金额／用途、算式、分类与合计，但提交按钮变上传截图；文字本身不能直接创建支出。
- 上传并保存凭证后，按精确金额自动匹配待记行。只有金额唯一对应时自动关联；同金额多行、多图同金额、识别失败、金额不符均提供手动匹配。
- 核对页面清楚展示用途／分类／金额、截图编号和识别金额；可按需查看截图，手动修正匹配。每笔待记支出必须有已保存截图，未配置/上传失败/仅识别均不允许文字支出入账。
- 不静默改写用户录入的金额、用途、类别或日期，不根据同额任意猜测；未关联图片明确提示，不伪称已附截图。
- 保留明确核对确认、取消不写账、重复确认保护、部分成功重试不重复、输入与草稿保留、账户/页面/弹窗异步隔离和历史编辑退款。
- 使用现有shadcn组件与宋体/窄屏规范；完成测试与浏览器验收，自动同步main并验证发布。

## Acceptance
- [x] 收入入口独立，稳定创建income，支出草稿保持，编辑/退款功能可用。
- [x] 支出文字提交只触发选图，无POST；已存图唯一金额自动关联，其余可手动匹配。
- [x] 无截图/未存图不能支出确认；取消、失败、部分写入和重试保持正确的原文/关联/身份。
- [x] 实际组件的选择菜单在弹窗上方可点击；桌面及320/390px匹配界面可用。
- [ ] 相关与全量测试、检查、构建、GitHub六项发布通过。
