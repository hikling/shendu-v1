# 六类验证日历修复与阶段日历收窄

用户截图显示六类复盘共用日期选择器在2026年11月出现重复的1、日期横向越界；需要修复共用入口。阶段与日历的左侧日历过宽，需要更紧凑的桌面比例。沿用六类配色、宋体、农历节气、阶段信息和已有权限／存储／日期等待期规则。

## 验收

- [x] 六类验证日历每个真实日期只出现一次，按星期一至日正确排列，日期和按钮均在框内；十月、十一月和跨年／闰年均正常。
- [x] Chrome普通环境、与My Fingerprint故障同类的时区API不一致环境、Edge及320/390/820px可用；翻月不选择日期，不丢导航焦点。
- [x] 空值保持空值，最早日期、今天、已选日期、锁定历史和单次原日期字段事件保持契约；周/月/季/年7/30/90/250天与决策三个月规则不变。
- [x] 阶段日历桌面日历卡片及网格更紧凑，列距均匀；标题／图例／农历节气仍清楚，右侧两面板总高继续对齐；窄屏无横向溢出。
- [ ] 原测试、构建和浏览器回归通过，按既有授权同步main并核对Linux CI。
