# 概览交互与居中日历

## 需求

- 六类入口增加阴影，单击在原位放大并从左侧展开信息，不移动其他五类；通过信息卡进入复盘。
- 顶部导航去除边框、底框与选中胶囊，以对应文字颜色标记当前页。
- 轮播卡片悬停反馈更明显，仍仅实际卡片悬停时暂停。
- 阶段与日历按钮打开居中、有层次的弹窗，保留现有阶段、日历和待验证功能。
- 不改变其他页面表单、数据或保存规则，兼顾手机、键盘和减少动态效果。

## 验收

- [x] 六类单击展开、放大与左侧信息不挤压其余图标，关闭/跳转可用且窄屏不出界。
- [x] 顶部导航无框、当前页文字有对应色。
- [x] 卡片有明显抬升/放大/阴影反馈，无悬停抖动，空白不误暂停。
- [x] 阶段日历居中弹窗可切月份、打开记录、编辑阶段、关闭并回焦，键盘不跑出。
- [x] 语法、浏览器回归、设计规范和README预览同步。
