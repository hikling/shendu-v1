# 阶段日历与插画历史页

## 用户要求

1. 阶段与日历左右各三张分类卡片从弹窗边框后伸出，只露出一部分，不是六张独立完整卡片。
2. 重设计该弹窗内部日历，月份、日期、今天和复盘状态更明显，延续纸感和六类插画风格。
3. 重做历史复盘 UI，合理加入已有分类插画。

## 验收

- [x] 桌面装饰紧贴弹窗边框并部分被弹窗遮住；窄屏不会挤压内容或横向溢出。
- [x] 月份与日期层级清晰；今天、草稿、已完成、已验证可区分且有文字图例；月份切换、原记录打开、无记录日期禁用保持。
- [x] 历史页展示六类对应配色与本地插画，标题、日期、摘要、状态清晰；搜索与类型／年／月筛选及空状态正常。
- [x] 保留概览、六类填写流程、等待期、账户、接口与保存字段。
- [ ] 桌面／320／390／820px、键盘、减少动态效果和自定义主题通过检查；文档截图与仓库同步。
