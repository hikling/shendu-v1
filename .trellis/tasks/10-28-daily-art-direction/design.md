# Art direction: 蓝墨光场

## Brief / boundary
用户认为原设计缺少艺术风，明确授权不受原框架/UI限制，自由发挥。重做 daily 引导与逐题画面，不改概览、其他五类、服务器与记录结构。保留已经接受的打字机、单题、前后切换、手动保存、dirty保护和历史/锁定规则。允许 daily 使用完整专属画布和自己的轻量导航，包括引导页隐藏共享顶部菜单；退出后必须恢复其他路由。

## Visual plan
- Palette: 雾蓝 #E9EDF7、纸白 #F8FAFF、浓墨 #152B54、群青 #315BE5、浅蓝 #B8CEF4、珊瑚 #E97961（限错误/少量细节）。主题色应融入墨晕/按钮或局部强调，可读文字保持深墨，浅色自定义主题仍可用。
- Type: 已有本地中文宋体承担大型中文显示/题目，Noto Sans SC承担输入提示/操作；数字独立大字号，用实际睡眠/精力数值作为画面主角。中文字体是慎独自省/手稿语义，避免只把旧文字放大。
- Layout: 全幅画布，左侧偏心文字与书写区，右侧越界蓝墨光晕/巨型场景汉字；顶部极简品牌/退出，底部真实进度和前后操作，不用暖米色卡片堆叠。手机转为上文下景、意象退到背景边缘，控件不遮挡。
- Signature: 一团有层次、边界不规则的“墨与光”形体，叠加巨幅半透明汉字。引导用「独」，睡眠用「眠」，精力用「息」，其余按真实题意切换。它是整个画面唯一强视觉锚点，不能再堆装饰徽章、统计卡和无意义英文。
- Motion: 保留按全文排版的打字机；每次进题只做短暂场景/题目入场，输入期间稳定。场景更换可以柔和改变墨晕位置/色调。无无限漂浮干扰，减少动态效果静止，装饰不参与焦点/指针。

```
desktop: [慎獨/退出]                          [当前日期]
         大字引导/当前题          巨幅「独/眠」与蓝墨光场
         透明书写区/巨大数值
         保存状态                    上一题 → 下一题
mobile:  极简退出 / 当前组与题号
         大题目 + 提示
         独立填写区（意象淡化于一侧）
         保存 / 前后操作
```

## Self critique
单纯纸色+宋体+细线仍会复刻用户拒绝的界面。风险集中在真正有占比的蓝墨形体、偏心构图与场景汉字；其余操作克制。艺术不能遮住输入、降低对比或杜撰记录含义；场景glyph仅装饰且aria-hidden。优先原生CSS/代码内矢量来制作形体，无外部资产/依赖/播放器，不生成不必要的图片。

## Canonical behavior
app.js继续拥有字段/题序/事件，daily-flow.js的规则不变。新场景只读取当前题/组；所有字段保持DOM挂载。复用现有 modal/toast/attemptNavigate、busy保护、历史快照与字体。shell/auth/退出清理daily专属画布和计时器；401保持当前题。静态资源版本升级。回滚前端提交即可，无数据迁移。
