# 实现边界

现有共享 shell 在宽屏给 `.workspace` 分配326px常驻 `.right-rail`，而概览单独隐藏；顶部栏和工作区偏移分别使用72px/64px固定值。概览轮播本身在 `.overview-reel` 紧接六类入口。只改共享 shell 的CSS布局和必要关闭态可访问性，保留唯一 `#right-rail` 以及既有日历、事件和嵌套弹窗。

通过共享头高变量协调头部、workspace、滚动偏移、移动菜单和概览最小高度：桌面约60px、手机约56px，适度缩小品牌，保留可用的按钮命中区；旧页面主体顶部内边距稍减。轮播以小幅负边距或安全方案上移，必须验证每个可见旋转角和hover均不裁切、不遮挡六类入口与展开信息，键盘/减少动态效果静态布局亦检查。索引页内容向上移动可适当减小hero顶部留白。保持记录、复盘页内容和轮播选取不变。

预期改动 `styles.css`、必要的 `app.js` 和入口缓存版本，以及适用的规范、README截图和任务记录。不调整数据库、API、其他页面业务。
