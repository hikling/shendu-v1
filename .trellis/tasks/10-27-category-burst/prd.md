# 六类环绕散开与直接进入

## 需求与边界

- 参考用户给定 LottieFiles 成功动画，悬停六类图标时出现向四周散开的粒子与扩散环，保持现有放大、阴影、介绍卡与固定位置。
- 单击图标即可通过现有导航进入对应复盘，介绍内按钮同样可进入。手机也单击直达。
- 本地CSS/装饰节点表现散开节奏，不新增外部运行依赖、网络请求或替换原插画。动效为每次进入一次短促散开，不持续循环；系统/账户减少动态效果时隐藏粒子。
- 修改app.js、styles.css、index.html缓存版本及文档/预览；其他页面主体、API与数据规则不改。

## 验收

- [x] 六类悬停可见四周散开，粒子不挡点击、不改变布局、离开后再次进入可重放。
- [x] 六类图标单击和键盘激活均直达正确页面，介绍按钮及手机仍可用。
- [x] 减少动态效果、边界和焦点关闭验证通过，规范、README、预览同步。
