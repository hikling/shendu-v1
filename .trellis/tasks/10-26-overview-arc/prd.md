# 概览弧形长卷与文案调整

## Goal

按用户最初参考图修正概览：记录沿两侧高、中央低的弧线连续循环，主句整体上移并删去指定辅助文字。

## Requirements

- 六类入口下的记录沿弧形路径移动，卡片方向随弧线变化，循环接缝在屏幕外。
- 删除可见的暂停移动按钮及其事件；悬停和键盘阅读、系统及账户减少动态效果设置继续可用。
- 删除「私人复盘空间」「选择一个时间尺度」「从已完成的复盘中随机拾起一页。」。
- 上移主标题区域，保留主句、主句下的说明和六类入口。
- 已完成记录筛选、随机顺序、原记录跳转保持现有规则。

## Acceptance Criteria

- [x] 桌面截图能看到两边高、中间低的记录弧线；连续移动时卡片沿弧线改变高度和角度。
- [x] 指定文案及暂停按钮均已删除，主标题比原版本靠上。
- [x] 窄屏无文档横向溢出，记录可点击；键盘和减少动态效果仍能阅读所有原始卡片。
- [x] `npm run check` 通过，静态资源版本更新，设计文档与规范同步。

## Change boundary

行为落在 `renderOverview()` 和概览 CSS。只调整概览模板、运动初始化和对应样式；共享 shell 增加离页时释放尺寸观察器。同步入口 HTML 缓存版本、DESIGN.md 和概览规范。无 API、记录格式、其他页面主体或保存行为修改。
