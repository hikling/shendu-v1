# 验证记录

## 实现与范围

- `renderOverview()` 删除三处指定文案和暂停按钮；账户菜单中的同名「私人复盘空间」也删除。
- 卡片改用 CSS motion path，每张沿自适应二次曲线向左运动并随切线转动。多余路径和循环接缝位于视口外，按卡片数、实际宽度和 CSS 间距计算周期，避免记录多时重叠。
- `ResizeObserver` 跟随窗口尺寸；`shell()` 离页时断开观察器，认证页面替换后观察器也会自行释放。CSS/JS URL 更新为 `1.0.0-overview2`。
- 其他页面主体和 API 无修改。记录筛选、随机取样和精确 ID 跳转沿用原逻辑。

## 浏览器验证

使用 Playwright 驱动本机 Edge，启动隔离数据目录的真实 Node 服务并注册合成测试账户；仅记录读取接口使用合成记录，不使用私人数据。

- 桌面 1660px：标题顶部从原实现的 226px 移到 120px，上移 106px。
- 900ms 前后测量卡片中心，横坐标和纵坐标均变化；中央卡片比两端更低。按完整周期的 0%、25%、50%、75%、99.9%、100.1% 采样，可视范围各有 5 张中心点，没有循环空窗。
- 悬停暂停；鼠标点击进入匹配原记录。键盘聚焦转为静态滚动列表，只显示 6 张原始卡；Enter 可进入记录。
- 系统与账户减少动态效果均使 `animation-name:none`，只保留原始卡。自定义主色正常应用。
- 390px 手机截图无文档横向溢出。运行中调整至 320、760、960、1440px，路径重新计算且无文档横向溢出。
- 单条记录能补足运动卡，草稿不进入长卷；12 条长标题/长摘要不溢出卡片，HTML 特殊字符按既有转义路径显示；空记录状态可进入每日复盘。
- 浏览器 `pageerror` 为 0。截图为 `docs/overview.png`，手机版截图及测量 JSON 保存在忽略的 `shendu/tmp/`。
