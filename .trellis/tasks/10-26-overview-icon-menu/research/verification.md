# 实现与验证

## 已确认的交互

用户选择「悬停或键盘聚焦时在左侧显示类别名称，单击直接进入页面」。浏览器已观察 Coffee options 的小方块、名称展开和图标反馈，使用项目已有语义 SVG 与 CSS 实现，不增加运行依赖。

## 变更边界

- 概览六类入口默认只有图标，复用 `NAV_ICON_PATHS` 和 `data-nav`，按钮的 `aria-label` 始终包含完整类别。
- 桌面方块 64px；悬停或 `:focus-visible` 时在左侧展开名称，图标短暂弹动。窄屏 50px / 44px 并预留名称空间；减少动态效果时显示名称但禁用过渡和弹动。
- 删除长卷两行标题、空状态中的同名标签与对应旧 CSS。弧线路径顶部基准从 90px 调至 60px，移除长卷顶部外边距。
- 静态资源缓存版本更新为 `1.0.0-overview3`。README 文字及 `docs/overview.png`、DESIGN.md 和前端规范同步。其他页面主体和数据规则无变更。

## 浏览器实页

通过 CUA 驱动浏览器，临时本地服务读取实际 `public/` 资源，以合成 `/api/*` 数据验证前端。没有使用私人数据。前后版本在同一 1660px 视口测量。

- 旧长卷窗口顶部 742.75px，新版 521.17px，上移约 222px；路径基准再上移 30px。中央卡片中心约 y731px，两侧约 y685px，弧线保留。
- 默认六个按钮均为 64×64px，名称透明且收起。实际鼠标悬停每周图标后，名称 opacity=1、完整宽度，右边 724px，小于图标左边 736px，悬停没有跳转。
- 六类依次一次点击，主区域都离开概览，文档标题分别为对应复盘类型。手机键盘聚焦 90 天入口并按 Enter，同样进入对应页面。
- 320、390、680、760、960、1280、1660px 均逐一聚焦六个按钮，所有名称完整、位于图标左侧、在视口内且无文档横向溢出。账户减少动态效果模式下名称仍显示，动画禁用；系统减少动态效果 CSS 用同等优先级覆盖 hover/focus 动画声明。
- 空记录状态不含两处已删除文字，正常记录状态也不含这些标题。合成记录仍沿原弧形路径移动。
- 截图：默认概览 `docs/overview.png`；展开效果与手机版截图、测量 JSON 在忽略的 `shendu/tmp/`。
